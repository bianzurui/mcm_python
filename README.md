# MCM Python Learning

This repository is my personal learning space for the **Mathematical Contest in Modeling (MCM/ICM)**.

I created this repository to improve my Python programming skills, learn mathematical modeling methods, and prepare for future MCM/ICM competitions.

## 🎯 Goals

- Learn and practice Python programming.
- Understand common mathematical modeling methods.
- Practice data analysis, visualization, and model evaluation.
- Record my learning progress and solutions to practice problems.
- Gradually build the programming skills needed for mathematical modeling competitions.

## 📂 Repository Contents

This repository contains learning materials and practice files, including:

- **Python scripts (`.py`)** — coding exercises, modeling experiments, and practice programs.
- **Data files (`.csv`)** — datasets used for data analysis and modeling practice.
- **Plots (`.png`)** — visualizations and results generated during experiments.
- **Notes and other files** — supplementary learning materials and explanations.

The contents may change as I continue learning and improving my modeling skills.
