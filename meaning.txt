==================== 美赛Python代码速查表 ====================
【一、符号速查】
符号          中文意思               作用                          例子
=             赋值                   把右边结果存进左边变量         res = 结果
==            判断是否相等            返回True/False                df["a"]==1
> < >= <=     大小比较                判断条件                     df["数值"] > 20
" " / ' '     英文引号                包裹文字、列名                df["数值"]
[ ]           方括号                 取列 或 筛选行                df["列"] / df[条件]
.             英文小数点              调用功能（方法）              df.mean()
( )           圆括号                 函数，存放参数                print(内容)
#             井号                   注释，不会运行，写笔记用      # 这是注释
,             逗号                   分隔多个参数                  plt.plot(x, y)
_             下划线                 变量命名，代替空格            df_fill

【二、缩写/变量名解释】
缩写            全称含义                说明
pandas         表格处理工具包          读取csv、筛选、统计
pd             pandas简写              约定俗成简写
matplotlib     画图工具包              画折线、柱状图
plt            matplotlib.pyplot简写   画图专用简写
df             DataFrame整张表格       读取csv后得到的表格
df_fill        填充缺失值后的表格       自己命名，fill=填充
res            result（结果）          筛选后得到的新表格

【三、Pandas 表格操作】
代码                          含义                 用途
pd.read_csv("x.csv")          读取csv文件           加载数据集
print(df)                     打印全部数据          查看原始数据
df.columns                    查看所有列名          排查KeyError最重要
df.describe()                 描述性统计            一键计算均值、最值、标准差
df["列名"]                    取出单独一列          提取一竖列数据
df[判断条件]                  筛选符合条件的行       挑选满足条件的数据
.mean()                       求平均值              计算一列平均
.sum()                        求和                  计算总和
.max() / .min()               最大值 / 最小值        找极值
.isnull().sum()               统计缺失值数量         查看每一列有多少空单元格
.dropna()                     删除含有空值的整行     直接剔除脏数据
.fillna(值)                   填充空单元格           用均值等填补空白
.copy()                       复制一份表格           备份原始数据，防止破坏原表
.to_csv("新文件.csv")         导出保存新csv文件      保存清洗完成的数据

【四、Matplotlib 绘图代码】

plt.plot(x, y)                绘制折线图             时间趋势图
plt.bar(x, y)                 绘制柱状图             分类对比图
plt.xlabel("英文文字")         设置X轴标签            论文图片坐标轴

==================== 比赛使用关键提醒 ====================
1. 拿到新csv，第一步：print(df.columns)，确认列名！KeyError几乎都是列名写错
2. 修改代码只改3处：①列名 ②筛选条件（符号+数字）③图片名称、图片标题
3. 引号必须是英文双引号 ""，中文“”直接报错
4. 常见报错：
   KeyError：列名和csv表头不一致
   FileNotFoundError：csv文件不在当前文件夹，或者文件名写错
